# Guard Bands for TypeScript

TypeScript implementation of the
[Guard Bands](https://github.com/Cryptix-Security/guard-bands) cryptographic
boundary protocol and its MCP `tools/call` integration.

The package will be published as `@guardbands/core`. Protocol behavior is
defined by the language-neutral
[Python conformance suite](https://github.com/Cryptix-Security/guard-bands/tree/main/conformance).

> Early development: the package is not yet published to npm.
