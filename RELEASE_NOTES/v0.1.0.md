# Guard Bands for TypeScript v0.1.0

The first TypeScript release implements Guard Bands protocol v2 and its MCP
`tools/call` boundary for Node.js 20 and later.

## Highlights

- RFC 8785/JCS canonical JSON with byte-for-byte Python interoperability.
- HMAC-SHA256 and Ed25519 signing and verification.
- Inline text bands and detached JSON envelopes.
- Verification of protocol v1's portable subset for migration.
- Guarded MCP 2.x client calls and server tool handlers.
- Complete-result signatures plus visible Guard Bands around text outputs.
- Vendored Python-generated conformance vectors, including a full MCP exchange.
- Strict TypeScript, Biome, Vitest, Node 20/22/24 CI, CodeQL, and Dependabot.

## Status

This is an experimental, pre-1.0 release. It is available from GitHub and is
not yet published to npm. The joint independent review required before a
stable release is tracked at
https://github.com/Cryptix-Security/guard-bands/issues/31.

Install from GitHub:

```bash
pnpm add github:Cryptix-Security/guard-bands-ts#v0.1.0
```
